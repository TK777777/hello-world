# ops-navigation

一个基于 Python Flask 和 Docker 构建的轻量级现代化运维导航中心，支持网站红绿灯健康度探测、安全权限校验、自定义头像持久化与炫酷彩光分类高亮。


# 🚀 Ops-Nav 运维导航中心

一个轻量级、现代化的企业级运维网址导航与健康监控系统。旨在帮助运维与开发团队高效管理内部各类系统（如 CI/CD、监控、堡垒机等），并实时监控网页健康状态。

## ✨ 核心功能

1. **🧭 侧边栏目录与快速定位**：左侧展示分类目录，点击任意分类可平滑滚动至对应区域，并伴随**炫酷彩光环绕旋转特效**进行高亮展示。
2. **🟢 网页健康状态实时探测**：内置后端连通性代理测试，自动检测每个网址的存活性，并在右下角实时显示**绿灯（正常）**或**红灯（异常）**状态指示。
3. **🔒 安全权限校验**：删除分类或网址等高危操作均需输入管理员密码（支持环境变量自定义），确保生产环境安全。
4. **🖼️ 自定义头像持久化**：支持用户随时上传并更换导航页头像，后端自动持久化保存至宿主机挂载目录，重启不丢失，同时浏览器标签页（Favicon）实时同步。
5. **🛠️ 模块化管理**：将“新建分类”、“删除分类”与“录入新网址”功能统一收纳进管理弹窗，界面保持高度整洁美观。

---

## 📦 技术栈

- **后端**：Python 3.11, Flask, Requests
- **前端**：HTML5, CSS3, JavaScript (原生轻量实现，无冗余沉重框架)
- **部署**：Docker & Docker Compose

---

## 🚀 快速部署

### 1. 编写配置文件
确保根目录下存在 `docker-compose.yml` 和 `requirements.txt`。

### 2. 一键启动
# 自动构建镜像并后台启动
docker-compose up --build -d

### 3. 环境变量说明

在 `docker-compose.yml` 中可通过环境变量修改管理员密码：
environment:
  - TZ=Asia/Shanghai
  - ADMIN_PASSWORD=你的安全密码
